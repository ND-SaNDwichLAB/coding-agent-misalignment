# A0 portrait poster

`Main.dc.html` is a self-contained static page (3179×4494 px artboard).
Open it directly in a browser; no server or build step is needed.

- Theme colors live in the `:root` CSS variables `--accent` and `--gold`.
- Figures in `figures/` are SVGs converted from `../paper-source/figures/*.pdf`
  (`pdftocairo -svg in.pdf out.svg`).
